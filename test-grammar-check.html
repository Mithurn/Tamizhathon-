தமிழ் Grammar Check Test Page

This page is designed to test the Tamil AI Grammar Check feature.

How to test Grammar Check:

  1. Make sure the Tamil AI extension is loaded and the backend server is running
  2. Type or paste Tamil text with potential grammar errors in the fields below
  3. Select the text you want to check
  4. Right-click and choose "Tamil AI Assistant" → "Grammar Check"
  5. The right-side chat panel should open with grammar suggestions

Sample Tamil Text with Grammar Issues

Here are some examples you can copy and test:

  • நான் பள்ளிக்கூடம் போறேன் (should be: நான் பள்ளிக்கூடத்திற்கு போகிறேன்)
  • அவன் வீட்டுக்கு வர்றேன் (should be: அவன் வீட்டுக்கு வருகிறேன்)
  • நான் படிக்க்றேன் (should be: நான் படிக்கிறேன்)
  • அவள் எழுத்றேன் (should be: அவள் எழுதுகிறாள்)

Instructions for Testing

  1. Copy any of the sample text above
  2. Paste it into one of the text fields
  3. Select the text
  4. Right-click and select "Tamil AI Assistant" → "Grammar Check"
  5. Check if the chat panel opens on the right side
  6. Verify that grammar suggestions are displayed
  7. Test the "Apply Suggestion" and "Copy" buttons
